# YouTube Zen — popup redesign brief

Это снимок текущего popup Chrome-расширения **YouTube Zen** (чистит интерфейс
YouTube). Цель — редизайн popup: сделать удобнее и стильнее, сохранив
функциональность. Всё в папке `source/` — реальный рабочий код.

## Что это за popup

Окно, которое открывается по клику на иконку расширения в Chrome.
Фиксированная ширина **360px**, высота по содержимому. Тёмная тема с красным
акцентом (фирменный цвет YouTube-подобный `#FF2D2D`). Без фреймворков — vanilla
TypeScript + CSS, рендер через создание DOM-элементов в JS.

## Архитектура экрана (сейчас)

```
┌──────────────────────────────────────┐
│ [Z]  YouTube Zen          [мастер-○─] │  ← header: лого + название + общий вкл/выкл
├──────┬───────────────────────────────┤
│ ✦    │                               │
│ ◎    │   контент активной секции     │  ← body: слева узкий rail (иконки-вкладки),
│ ▶    │   (тумблеры / контролы)       │     справа контент выбранной секции
│ ◐    │                               │
│ ⚙    │                               │  ← ⚙ прижата вниз (position: bottom)
└──────┴───────────────────────────────┘
```

- **Header** — лого-квадрат с буквой Z, название, мастер-переключатель
  (выключает всё расширение; когда выкл — body визуально гасится классом
  `.disabled`).
- **Rail** (левая колонка) — вертикальный список секций иконками. Активная
  подсвечена. Иконки сейчас — юникод-символы (`✦ ◎ ▶ ◐ ⚙`), это слабое место,
  можно заменить на нормальные SVG-иконки.
- **Content** — рендерится секция, выбранная в rail.

## Секции (реестр в `sections.ts`)

| id | Название | Иконка | Статус |
|----|----------|--------|--------|
| `cleaner`  | Очистка UI    | ✦ | рабочая, самая большая |
| `filters`  | Фильтры ленты | ◎ | рабочая |
| `tools`    | Инструменты   | ▶ | заглушка (`stub`) |
| `themes`   | Темы          | ◐ | заглушка (`stub`) |
| `settings` | Настройки     | ⚙ | рабочая, внизу rail |

### Очистка UI (`section-cleaner.ts`) — главный экран
Список тумблеров «что скрыть на YouTube», сгруппированный по областям:
Лента / Сайдбар / Страница видео / Подвал. Часть пунктов сайдбара — вложенные
аккордеоны (мастер-тумблер + дети, например «Вы» → Плейлисты/История/...).
Данные тумблеров берутся из `selectors.ts` (`HIDE_RULES`, `SIDEBAR_LISTS`) —
дизайнеру важна структура: группы, вложенность, master/child.

### Фильтры ленты (`section-filters.ts`)
Контролы фильтрации: тумблер «скрывать просмотренные» + слайдер порога %,
и набор выпадающих списков для дефолтных фильтров поиска (дата/длительность/
сортировка/тип).

### Настройки (`section-settings.ts`)
Сейчас минимум — кнопка сброса к дефолтам и т.п.

## Данные, которые отражает UI

- `types.ts` — `ZenSettings` (все настройки), `HideRule`, `SidebarList` (структура
  вложенных тумблеров), `GROUP_LABELS` (рус. названия групп).
- `defaults.ts` — дефолтные значения.
- `selectors.ts` — `HIDE_RULES` и `SIDEBAR_LISTS`: ровно тот список пунктов и
  групп, что рисуется в «Очистке UI». Полезно, чтобы понять реальный объём
  контента (сколько тумблеров, какая вложенность).

## Что хочется от редизайна

- Тот же набор функций и секций, но удобнее и современнее.
- Лучше иконки в rail (сейчас юникод-символы).
- Аккуратнее группы тумблеров и вложенные аккордеоны в «Очистке UI».
- Сохранить: ширину ~360px, тёмную тему, красный акцент, системный шрифт,
  отсутствие фреймворков (чистый CSS/HTML — артефакт можно отдать как HTML+CSS).

## Технические ограничения (для реализуемости)

- Ширина popup фиксированная (~360px), вертикальный скролл допустим.
- Vanilla, без React/Tailwind в проде — но мокап можно делать любым удобным
  способом, главное чтобы стиль/разметку потом перенести в CSS.
- Иконки — желательно inline SVG (работает офлайн, без внешних шрифтов).

## Файлы в `source/`

- `popup.html` — каркас (header + rail + content).
- `popup.css` — все стили и токены (главный файл для редизайна).
- `popup.ts` — оркестратор (rail/контент/реакция на storage).
- `sections.ts` — реестр секций.
- `section-*.ts` — рендер каждой секции (cleaner — основной).
- `types.ts` / `defaults.ts` / `selectors.ts` — модель данных и наполнение.
- `utils.ts` — мелкие хелперы.
