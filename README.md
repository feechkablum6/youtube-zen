# YouTube Zen

<img src="icons/icon-128.png" width="96" alt="youtube-zen">

Расширение для Chrome, которое убирает лишнее с интерфейса YouTube: Shorts, мусор в боковом меню, футер, рекламные заглушки и другие отвлекающие элементы. Управление собрано в компактном popup, всё скрытие происходит через CSS без удаления элементов страницы.

## Возможности

- Скрытие Shorts в ленте и в боковом меню.
- Очистка бокового меню: разделы «Вы», «Навигатор», «Другие возможности», кнопки «Главная», «Подписки», «История», «Плейлисты», «Смотреть позже», «Понравившиеся», «Ваши видео», «Скачанные», а также «Музыка», «Фильмы», «Трансляции», YouTube Music и YouTube Детям.
- Скрытие футера, кнопки жалобы, панели действий под видео и кнопки-меню (☰) в шапке.
- Фикс пустых рекламных контейнеров и in-feed рекламы, остающихся после uBlock.
- Фильтр ленты по проценту просмотра: прятать карточки, досмотренные выше заданного порога.
- Пресеты фильтров поиска: дата загрузки, длительность, сортировка и тип результата.
- Общий выключатель для мгновенного включения и отключения всех правил.
- Настройки хранятся в `chrome.storage.sync` и синхронизируются между устройствами.

## Установка

Расширение не опубликовано в Chrome Web Store, ставится вручную из собранной сборки.

1. Установить зависимости: `npm install`
2. Собрать проект: `npm run build` (результат в папке `dist/`)
3. Открыть `chrome://extensions`, включить «Режим разработчика».
4. Нажать «Загрузить распакованное расширение» и указать папку `dist/`.

После любого изменения исходников нужно пересобрать проект (`npm run build`) или держать запущенным watch-режим (`npm run dev`), так как Chrome загружает `dist/`, а не исходники.

## Использование

Иконка расширения открывает popup с разделами. Слева — навигация по разделам, справа — переключатели:

- Очистка UI — тумблеры для каждого скрываемого элемента.
- Фильтры ленты — фильтр по проценту просмотра с настройкой порога.
- Настройки поиска — пресеты по дате, длительности, сортировке и типу.

Верхний общий выключатель включает и отключает все активные правила сразу.

## Команды разработки

- `npm run build` — production-сборка в `dist/`
- `npm run dev` — сборка в watch-режиме
- `npm test` — запуск тестов
- `npm run test:watch` — тесты в watch-режиме
- `npm run typecheck` — проверка типов

## Технологии

- TypeScript (strict), Manifest V3
- Vite + esbuild
- Vitest + jsdom для тестов
- Vanilla DOM, без фреймворков
